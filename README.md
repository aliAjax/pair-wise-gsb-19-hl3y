# hxwl-05 水族箱水质监测

多鱼缸水质趋势、换水和异常指标提醒

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **鱼缸建档**：草缸 / 海缸 / 三湖缸，记录名称、维护人、水体容积
- **水质记录**：pH、氨氮、亚硝酸盐、硝酸盐、硬度、温度，附换水比例和测量时间
- **趋势图**：按缸查看六项指标走势，氨氮 / 亚硝酸盐带限值参考线，超线点红色高亮
- **异常提醒**：氨氮或亚硝酸盐超过缸型限值时表单即时告警，必须填写处理备注才能保存；记录列表中异常记录红色标记
- **联动筛选**：按鱼缸类型或维护人筛选，统计卡片、趋势图、异常数量和最近记录同步更新
- **本地持久化**：数据保存在 localStorage，重开页面可继续记录；首次打开内置近两周示例数据

## 安全限值（ppm）

| 缸型 | 氨氮 | 亚硝酸盐 |
| ---- | ---- | -------- |
| 草缸 | 0.20 | 0.20 |
| 海缸 | 0.10 | 0.10 |
| 三湖缸 | 0.25 | 0.25 |

限值定义在 `src/types.ts` 的 `THRESHOLDS`，可按店内标准调整。
