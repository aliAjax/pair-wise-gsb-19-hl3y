# hxwl-05 水族箱水质监测

多鱼缸水质趋势、换水和异常指标提醒

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **鱼缸建档**：草缸、海缸、三湖缸三类，记录名称、维护人、水体升数，可删除（连带记录）
- **水质录入**：pH、氨氮、亚硝酸盐、硝酸盐、硬度、温度，附换水比例和记录时间
- **超标管控**：氨氮 / 亚硝酸盐超过缸型上限时字段高亮、红点标记，必须填写处理备注才能保存
  - 草缸：氨氮 ≤ 0.2 ppm，亚硝酸盐 ≤ 0.2 ppm
  - 海缸：氨氮 ≤ 0.1 ppm，亚硝酸盐 ≤ 0.1 ppm
  - 三湖缸：氨氮 ≤ 0.25 ppm，亚硝酸盐 ≤ 0.3 ppm
- **趋势图**：每口缸六项指标折线趋势，氨氮 / 亚硝酸盐带超标虚线，悬停查看单点数值
- **联动筛选**：按鱼缸类型或维护人筛选，统计卡（异常数量等）、趋势、最近记录一起更新
- **持久化**：数据保存在浏览器 localStorage，重开页面可接着记录；首次打开写入三口缸近三周的示例数据便于演示
